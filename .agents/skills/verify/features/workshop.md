# Proof workshop

Enter from Library, the topbar, sidebar, or attached MH2100 lessons. Run `npm run agent -- browser run --features workshop`.

The journey submits learner-built coefficients, exponents, and ordered polygon vertices through labeled native controls. It checks invalid-field and result focus, exact scope boundaries, the C=3 certificate, wrong-map and too-small-bound distinctions, a nondecisive parabola, a tiny nonzero cubic coefficient, loop reversal, singular-edge refusal, and zero winding. Changing C, the path exponent and coefficient, and traversal order must change finite SVG geometry. KaTeX and text equivalents accompany the proofs and numerical illustrations.

It preserves each initial explanation with its construction, report and revisions, hides stale current results during reconstruction, inspects older attempts, switches investigations, and follows lessons with return, Back and Forward. It uses the keyboard at 320px, checks page overflow at 200 percent CSS zoom and reduced motion, and verifies selection-only links, invalid-link recovery, reload reset and absence of workshop account writes.

This is local Chromium evidence. It does not certify participant usability, screen-reader operation, mastery, native sign-in, public deployment or private source access.
