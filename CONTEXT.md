# Calculus — context

An interactive mathematics learning application.

## Language

**Site**: the existing ChatGPT Sites deployment; GitHub stores its reviewed source snapshot.

**Course reference**: a link or citation to learning material. A link does not redistribute the
referenced file or grant permission to copy it.

**Baseline**: the Organisation's centrally managed repository configuration and conformance checks.

**Course path**: the ordered lecture/chapter units for MH1100, MH1101 or MH2100.

**Exploration**: original mathematical notes plus a parameterised illustrative model and source citations.

**PDF page**: one-based physical page in the linked extract, not a printed textbook page number.

**Visual layout**: split notes/graph, wide graph, or minimised graph with expanded reading space.

**Comparison lab**: two or more analytic representations of an existing lesson, with
an exact readout and a prediction followed by explanatory feedback.

**Self-assessment**: a learner's own confidence record; never an automatic grade.

**Independent choice record**: a scored choice made without hints; limited evidence
about that choice, never a claim of mastery or learning gain.

**Clinic case**: an original decision, exact argument and distinct transfer question, with choice-specific feedback and recovery into an existing lesson.

**Clinic attempt**: a draft or committed choice plus ungraded scratch work, held only in the current Atlas tab session. Case switches and recovery retain it. Reload clears it. It is never an account record or a mastery claim.

**Clinic recovery**: a lesson detour with a validated case, fixed focus token and bounded scroll position belonging to its history entry. Returning restores the current tab attempt.

**Account record**: one validated personal value owned by the native stable Site user ID.
Email and name describe the account and do not authorize data access.

**Save acknowledgement**: D1 accepted the current edit for the current account. A queued,
guest, offline, conflicting, or superseded edit has no such acknowledgement.

**Legacy attempt**: historical device evidence imported explicitly. Its recorded correctness
is preserved rather than presented as a newly verified answer.

**Captured time**: when the learner checked a choice. **Acceptance time** records when D1
accepted it. Delayed saving does not change the captured time.

**Source fingerprint**: SHA-256 of tracked and nonignored files, including contents,
paths, symlink targets and executable flags; distinguishes edits sharing a Git HEAD.

**Browser evidence**: attributed observations of a stated source and URL. Machine
validation checks its shape and provenance, not whether the observations happened.

**Bounded braces fork**: the private, locally vendored braces 3.0.3 derivative used by build dependencies. Calculus maintainers own its fixed traversal limits and upstream retirement decision in [ADR-0009](docs/adr/0009-own-a-bounded-braces-fork.md).
