# Why Clinic keeps attempts in tab memory

Calculus Clinic adds original diagnostic practice beside the existing library, lessons and graph studio. Its nine cases each pair a committed decision with a distinct transfer question. Choice-specific feedback identifies a missing assumption and links to the existing lesson that repairs it. The exact argument appears after the first commit. Written reasoning stays ungraded.

The architecture exploration compared controller-owned attempts with an Atlas-lifetime session. The selected design uses the latter and the former's four-phase two-question union. One reducer owns each case's draft, committed decision, transfer and scratch work. It remains mounted through lesson recovery and case changes. Reload starts a fresh session. This gives the interface a clear lifetime without adding an account record, answer serializer or storage migration.

The existing study controller remains the only location observer. Clinic navigation uses a strict, bounded versioned case URL. Existing view writers remove stale Clinic parameters, and Clinic removes the other known view parameters while preserving unrelated parameters. The controller handles recovery through ordinary lesson URLs without calling the account-writing lesson-open action. An entry-specific descriptor contains only a validated case, fixed focus token and finite bounded scroll position. Return restores the same in-tab attempt. Reload retains the selected case and clears answers, including on a recovery detour.

Native radios keep keyboard behavior. Explicit commit controls distinguish a draft from feedback. Feedback receives focus after each commit. Picker, case and recovery navigation share the controller's focus and scroll intent so an unconditional lesson effect cannot erase restored positions. The active case and picker live in separate cohesive views. The catalog's insertion order owns case order and IDs.

The original mathematical cases cover Rolle's hypotheses, composition, L'Hôpital's nonconverse, improper cancellation, absolute convergence, power-series endpoints, total differentiability, conservative domains and oriented flux. Existing lesson IDs and source references remain unchanged. Authored answer keys and formulas receive independent mathematical review. Model, codec, catalog and KaTeX tests check product contracts. The maintained real-browser journey drives all nine decisions and transfer checks, recovery, history, reload, invalid links, keyboard controls and 320px layout.

Accepted limits are transient attempts, authored-choice diagnosis and ungraded written reasoning. Clinic claims neither mastery nor participant outcomes. Native provider sign-in is outside this work. There are no implementation deviations from the selected synthesis. Browser verification, independent review and publication are separate release gates, not claims established by a successful build.
